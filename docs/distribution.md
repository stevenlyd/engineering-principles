## Verification and scope

`npm run check` validates manifest/version consistency, skill reference completeness and all relative Markdown links. Those checks do not prove every host installs or updates correctly. Host runtime receipts should identify client version, source revision, install/update command, discovered version and reload boundary. A marketplace refresh alone is not proof that an active session changed. Do not claim another person's machine was tested.

No new agent binary, credential, GitHub App grant, public directory listing, or auto-update setting is installed by these files. Existing copied installations need a one-time reviewed move to the chosen native channel; preserve edits and confirm native discovery before removing duplicates. Rollback uses the host's supported reinstall/ref selection, or the project's immutable policy resolution, without overwriting managed caches.
